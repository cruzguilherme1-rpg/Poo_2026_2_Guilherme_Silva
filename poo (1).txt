Conceitos iniciais de POO
1. Classificação: reunião de grupos objetos com caracter´sticas semelhantes. Geram classes.

2. Entidades: coisas do mundo real que precisam ser representadas por um software.
    ->Em uma modelagem se identificam as entidades, as informações(dados) e as operações(o que faz).

3. Abstração: identificação e comportamentos importantes para representar um objeto no software.
    ->Ex: modelagem de triângulo usa a entidade, dados e operações.


*Modelos de Entidades*
1. Programação Estruturada: uso de estrutura e função no modelo das entidades.
    Limitações:
        ->Dados podem ficar inválidos,pois não consegue restringir certos valores.
        ->Para resolver esse problema, usa-se o encapsulamento.

2. Programação Orientada a Objetos:
    ->Operações usam métodos
    ->Armazenamento de informações nos campos ou atributos
    ->Classes modelam entidades e tem campos e métodos.

3. Referência e Instância:
    ->Variáveis são alocadas quando uma atribuição com o nome de classe é realizada.
    -> A variável é chamada de referência.
    -> A Instância da classe(objeto ) é criada pela instrução.
    -> A variável não é o próprio objeto e sim uma referência para o objeto criado. 
->C++ x Python : C++ a variável é a instância e o próprio objeto, armazenando dados nos atributos.
Python a variável é uma referência para a instância e a variável guarda um endereço de memória.
2.1.Modelagem/Exemplos em linguagens
->C++
class Triangulo {       //Tipo de Variável
public:
    double b, h;        //Atributos
    double calcular_area(){     //Método
        return b*h / 2;
    }
};

int main(){
    Triangulo x;
    x.b=10;
    x.h=20;
    cout<< x.calcular_area();
}

->C
struct Triangulo{       //Tipo de Variável
    double b,h;     //Campos
};
double calcular_area(Triangulo t) {
    return t.b*t.h /2;
}
int main(){
    Triangulo x;
    x.b=10;
    x.h=20;
    printf("%lf", calcular_area(x));
}

->Python
class Triangulo:        #Tipo de Variável
    def __init__(self):     #uso do __ chamasse de método mágico
        self.b = 0      #Campo ou atributos
        self.h = 0
    def calcular_area(self):
        return self.b * self.h /2       #Método
x=Triangulo()
x.b=10
x.h=20
print(x.calcular_area())
